## Méthode (ordre de travail)
1. Pour chaque donnée : chercher dans la littérature savante (livres/articles universitaires, dictionnaires savants, BnF/Gallica, data.bnf.fr, Archives nationales), en français et dans les autres langues utiles.
2. Recouper : ≥ 2 sources indépendantes dont ≥ 1 universitaire. Noter dans `docs/sources/<chantier>.md`.
3. Concordance → on garde. Divergence entre spécialistes → mention attribuée ou on s'abstient. Pas de source solide → **on ne pousse pas** et on signale.
4. Corrections en base : non destructives par défaut (valeur corrigée + trace dans le registre) ; suppression = accord de Martin.
